# 项目长期备忘 · 北宋杨家将

## 项目性质
把湖南美术出版社连环画《北宋杨家将》（全八册）改编为动画作品。当前阶段：创意与剧本开发。

## 源材料
- 位置：`漫画/` 下 8 个 PDF，共 672 页，1024×768 横构图，**无文字层**（纯扫描）
- 目录：①杨令公归宋 ②邠阳城救驾 ③殉国李陵碑 ④六郎收三将 ⑤八姐闯幽州 ⑥智救杨郡马 ⑦大破天门阵 ⑧穆桂英挂帅
- 改编 喻岳衡；绘者依次为 蒋太禄 / 贺宣华 / 陈安民 / 郑一呼 / 张治华 / 邓立衍·邓大鹰 / 廖正华 / 罗苍诗

## 已定方案（后续沿用，勿轻易改）
- **片名**《杨家将 · 忠烈千秋》；结构 三季 24 集 × 22 min
- **视觉风格名**「新白描」（= 上美影手绘动画风格）：白描为骨 + 宣纸底 + 淡彩平涂；禁用写实光斑、渐变阴影、数字运动模糊
- **剧组色盘**：青瓷绿、朱砂红、鎏金、墨黑（主四色）+ 赭石、月白、绛紫、石青（扩展色）
- **朱砂纪律**：全片仅三处用红——归宋誓师（第2集）/ 杨业殉国（第6集）/ 桂英挂帅（第23集）
- **贯穿意象**：李陵碑，同机位拍三次（第8集无字碑 → 第21集刻满名字 → 第24集碑前开花）
- 交付物在 `动画改编方案/` 目录
