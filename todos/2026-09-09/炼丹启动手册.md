**日志三件套**（都在 `D:\ai_projects\ai-toolkit\`）：

**看门狗判活逻辑**（2026-09-09 修正版）：
- 训练子进程带 `PYTHONUNBUFFERED=1`（否则块缓冲导致日志不增长 → 误杀）
- 判挂死条件 = 日志 40 分钟无增长 **且** VRAM < 8GB（模型停驻 CPU 时显存会掉下来）
- 日志不涨但 VRAM ≥ 8GB → 判定缓冲未刷，放行继续观察

## 五、已踩过的坑（重要，防复发）

| # | 坑 | 症状 | 解法 |
|---|---|---|---|
| 1 | `low_vram: true` 在训练/采样阶段把 12B 模型停驻 **CPU**（quantize.py legacy 分支） | baseline 采样 104 分钟/张、0 步训练后驱动崩溃(nvlddmkm) | `disable_sampling: true` + `cache_text_encoder_to_disk: true`，训练时模型驻 GPU |
| 2 | ComfyUI 与训练抢显存 | 加载期 0xC0000005 访问违例崩溃 | 流水线启动/重试前自动 `/free`；训练期间勿开 ComfyUI 重任务 |
| 3 | Python stdout 块缓冲 | train_log 40min 不增长 → 看门狗误杀正常训练 | `PYTHONUNBUFFERED=1` + VRAM 辅助判活 |
| 4 | hf_xet 在 Windows 下载大 LFS 文件 OSError(22) | 下载反复失败 | `HF_HUB_DISABLE_XET=1`；镜像 SSL 不稳时换 huggingface.co 直连 |
| 5 | HF 缓存校验查 `blobs/` 目录 | Windows 无符号链接模式文件直存 `snapshots/`，校验恒 0 | 校验改为 snapshots + 组件大小阈值 |
| 6 | ComfyUI 重启清空队列/历史（内存态） | 后台轮询脚本等永远不来的历史 | 长轮询脚本需检测 ComfyUI 进程存活/重启时间 |
| 7 | nvidia-smi 不在 PATH | PowerShell 报找不到命令 | 用全路径 `C:\Windows\System32\nvidia-smi.exe` |
| 8 | 训练脚本 GBK 解码崩线程（读中文 nvidia-smi 输出） | train_log 出现 UnicodeDecodeError | 无害（读线程），可忽略 |
