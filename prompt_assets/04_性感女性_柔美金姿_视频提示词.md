# 性感漂亮女性 · 柔美金姿 · 视频提示词

> 系列定位：**柔美 + 金姿** —— 低运动强度、流畅运镜、柔和光影；以呼吸感、发丝与织物飘动、缓慢仪态变化表达魅力。
> 上游首帧来自 [03 图片提示词](./03_性感女性_柔美金姿_图片提示词.md) 同编号场景（rm01~rm06 → mv01~mv06）。
> 配套：[06 视频通用负面词](./06_批量出图_负面提示词_通用.md)
> 本地管线：`tools/h3_fast_submit.py`（MiniMax H3 4 步 turbo / 9:16 / 原生音频）

## 通用约定

| 项 | 建议值 | 说明 |
|---|---|---|
| 画幅 | 736×1088（9:16 竖屏） | 竖屏构图突出仪态线条 |
| 帧数 | length 124（≈5s） | H3 输出遵循 `17n+5` 规律；需要更长按 `h3_fast_segmented.py` 分段 |
| 帧率 | 24fps | 与 H3 原生输出一致 |
| 运动强度 | 低～中 | 超慢镜头不宜（易"假"），剧烈动作会糊脸 |
| 音频 | H3 原生 AAC 音轨 | 提示词里写环境音描述即可，不用另外配音 |
| 运镜 | 单一运镜为主 | 一段只用一个运镜（推 / 移 / 环绕 / 升），避免大跳变 |
| 负面 | 见 06「视频通用」 | `jittery, flickering, morphing, warping faces, stuttering...` |

**三段式写法**：`主体状态 + 单一运镜 + 光线氛围`，动作只写 1~2 个（写多了必变形）。

## 首尾帧（FL2V）用法

段与段衔接、或想把"起势/收势"钉死时，用首尾帧版本（传 `--last-frame` 即自动切 FL2V 工作流）：

```powershell
python tools/h3_fast_submit.py --prompt-file mv03.txt --first-frame rm03_start.png --last-frame rm03_end.png
```

> `workflows/v5/h3_fast_fl2v_9x16_api.json` 的节点 19 `LoadImage` 已固定接 `[inject:last_frame]` 输入槽，由提交器自动注入。

## 排产与验收

1. **先图后视频**：mv01~mv06 的首帧必须先由 03 的 rm01~rm06 出图并目检通过。
2. **只提交不轮询**：长任务提交后即结束回合，完成由后台通知；手工查进度用 `python tools/_pc_status.py` 或 ComfyUI 队列页。
3. **产物归档**：`output/<YYYY-MM-DD>/<项目名>/`，H3 输出自带音频轨（AAC），拼接时务必 `-map [aout]`。
4. **运动验收**：低强度片重点看"脸不糊、织物不跳变、无 morphing"；如需动作保真度指标走 `tools/motion_fidelity_qa.py`。
