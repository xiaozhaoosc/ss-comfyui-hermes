# 角色三视图 / 设定图 通用模板

把 20 角色里任一段「角色描述」填入 {CHAR}，即可出设定图：

{CHAR}, character sheet, front view, side view, back view,
consistent character design, full body, neutral pose,
plain white background, high detail, professional character
design, 8K, no text, no watermark

## 一致性技巧（本地无护栏模型）
- 固定「角色描述」前缀，多次生成保持同一脸/同一设定
- 配合 LoRA / IP-Adapter / Reference 锁定人物
- 负面：inconsistent design, different face, extra limbs, bad hands
