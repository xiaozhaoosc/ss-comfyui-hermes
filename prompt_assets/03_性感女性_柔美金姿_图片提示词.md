# 性感漂亮女性 · 柔美金姿 · 图片提示词

> 系列定位：**柔美**（柔和光线、柔和质感、柔和姿态）+ **金姿**（优雅有型的身体线条与仪态）。
> 写实向、含蓄性感：以剪裁贴合、肩颈/锁骨/腿部线条与慵懒仪态传达魅力，不写露骨内容。
> 配套：[06 通用负面词](./06_批量出图_负面提示词_通用.md) ｜ [05 三视图模板](./05_角色三视图_提示词模板.md)
> 出图后端：Z-Image Turbo / FLUX.1 Dev fp8 / SDXL RealVisXL V4.0（管线：`tools/_pc_gen.py`）

## 通用约定

- **每档提示词都必须自带「着装锚点」**，因为 Z-Image 与 FLUX 在本机管线上 `cfg=1.0`，负面提示词不生效 → 着装与构图只能靠正向兜住。
- **负面提示词只有 SDXL 真实生效**（cfg 5.5），务必带 06 的负面块。
- 建议比例：**3:4 或 9:16**（竖构图，突出仪态线条）；单图步数见每节参数建议。
- 统一画质后缀：`soft cinematic light, delicate skin texture, natural film grain, sharp focus, photorealistic, high detail`。

## 首轮测试排产（3 后端 × 5 张）

| 项 | 值 |
|---|---|
| 场景 | rm01 ~ rm05（各 1 张） |
| 后端 1 | `zimage`（Z-Image Turbo bf16） |
| 后端 2 | `flux fp8`（FLUX.1 Dev fp8） |
| 后端 3 | `sd15 RealVisXL_V4.0.safetensors sdxl_realvis` |
| 产物目录 | `output/<YYYY-MM-DD>_wb/roumei/<backend>/` |
| 提交命令 | 见下方 |

```powershell
python tools/_pc_gen.py --backend zimage --scenes rm01_morning_camisole,rm02_sofa_recline,rm03_mirror_satin,rm04_backlit_linen,rm05_bed_stretch
python tools/_pc_gen.py --backend flux fp8 --scenes rm01_morning_camisole,rm02_sofa_recline,rm03_mirror_satin,rm04_backlit_linen,rm05_bed_stretch
python tools/_pc_gen.py --backend sd15 RealVisXL_V4.0.safetensors sdxl_realvis --scenes rm01_morning_camisole,rm02_sofa_recline,rm03_mirror_satin,rm04_backlit_linen,rm05_bed_stretch
```

> 每档固定 seed = 基址 + 场景序号（zimage 900000 / flux 710000 / sdxl 510000），三档同 seed 便于横向对比构图差异。
