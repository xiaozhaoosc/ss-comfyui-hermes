# 角色资产 · 21 角色提示词

> 用途：本地 ComfyUI 出图的角色资产底稿。生图后端（Z-Image Turbo / FLUX.1 Dev / SDXL / Qwen-Image-2.1 参考图锁脸）共用同一套「身份锚点」。
> 配套：[02 速查表](./02_角色资产_20角色_表格.md) ｜ [05 三视图模板](./05_角色三视图_提示词模板.md) ｜ [06 通用负面词](./06_批量出图_负面提示词_通用.md)
> 用法：先跑一次三视图（05 模板 + 本文件的「身份锚点」）锁定长相 → 之后所有场景提示词都带上同一段身份锚点做一致性锚。

## 通用规则

- **一致性靠「身份锚点」前缀**：同一角色所有图都必须原样带上它的身份锚点，不要改写。
- **Z-Image Turbo**：`cfg=1.0` → 负面提示词无效，着装/画面约束必须写进正向。
- **FLUX.1 Dev**：自然语言长句 + 明确着装描述（abliterated 底模需要正向锚住服饰）。
- **SDXL**：tag 风格 + 完整负面词（见 06）。
- 比例：角色立绘 2:3（竖）；三视图 1:1；参考 `05`。

## 一致性操作规范

1. **先锁脸**：每个角色先跑一次 [05 三视图模板](./05_角色三视图_提示词模板.md)，用「身份锚点」填 `{CHAR}`，得到正/侧/背三视图，目检通过后再铺场景。
2. **锁 seed**：同一角色在同底模下固定 seed（角色序号 × 100000），避免每次换脸。
3. **锁身份向量**：出图后如需入库，走 `tools/char_lib_add.py` 生成 512 维 insightface 向量，余弦相似度 ≥ 0.6 视为同一人。
4. **换底模要重跑**：Z-Image / FLUX / SDXL 三者的"同一张脸"并不通用，跨底模必须重新锁一次。
