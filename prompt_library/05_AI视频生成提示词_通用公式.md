## 一、视频提示词通用公式

视频提示词要比生图多写两类信息：**时间里的动作变化**，以及**镜头如何运动**。

```
[主体] + [初始状态] + [动作变化] + [镜头语言] + [场景氛围] + [风格质感] + [时长/节奏] + [负面约束]
```

| 变量 | 写什么 | 示例 |
|------|--------|------|
| 主体 | 人物、动物、产品或场景核心 | 穿黑色风衣的女性；一盏黄铜台灯 |
| 初始状态 | 视频第一帧或开始时的状态 | 站在雨夜街角，低头撑伞 |
| 动作变化 | 从开始到结束发生什么 | 缓慢抬头，看向镜头，雨水从伞沿滴落 |
| 镜头语言 | 景别、运镜、焦点、速度 | 中景推进到近景，轻微手持感 |
| 场景氛围 | 光线、天气、背景、情绪 | 冷蓝色霓虹，地面积水反光，悬疑氛围 |
| 风格质感 | 电影、广告、MV、纪录片、动画等 | 电影感，低饱和，浅景深 |
| 节奏 | 时长、速度、停顿、动作密度 | 5秒，慢动作，最后0.5秒定格 |
| 负面约束 | 不希望出现的崩坏点 | 无水印、无跳帧、无穿模、人物身份稳定 |
