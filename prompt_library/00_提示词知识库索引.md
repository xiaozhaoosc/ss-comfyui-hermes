## 三、使用说明

1. 每个提示词文件中的 `代码块 / Plain Text` 即提示词正文，**直接复制**到 ComfyUI / 视频模型的提示词框即可。
2. 中英混合写法：中文写意境与感觉，英文补精确参数（见 Z-Image 部分）。
3. 视频类提示词务必补齐「时间线 + 镜头运动 + 声音（H3）/ 负面约束」。
4. 源站持续更新，文件顶部标注的「修改时间」为源站最近更新时间。
