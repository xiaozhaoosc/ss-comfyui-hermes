# CHARACTER IDENTITY LOCK / 角色视觉身份锁

此文件包含该角色的核心身份特征定义。在生成任何图片或视频时，此段内容必须作为【最高优先级】固定在提示词最顶部。

## 英文版 (English Version - Recommended for Nano Banana Pro)

【CHARACTER IDENTITY LOCK — HIGHEST PRIORITY】
The following information defines the permanent visual identity of the character.
For every future image, preserve the same person, the same facial identity, the same body proportions, the same hairstyle, and the same costume identity.
She is NOT a newly designed character in each image.
She must always appear to be:
the exact same real adult woman.

FACIAL IDENTITY
Preserve the character's facial identity from the reference images with maximum consistency.
Maintain:
the same oval face shape
the same facial width-to-height ratio
the same forehead proportions
the same brow structure
the same eye shape, size, spacing, and outer-corner structure
the same nose bridge height
the same nose tip and nostril proportions
the same lip shape and volume
the same mouth corners
the same jawline
the same chin structure
the same ear placement and overall facial bone structure
Her identity must be recognized through the combination of:
eyes + nose + lips + jawline + face shape + facial proportions.
Do NOT redesign her facial features when the camera angle changes.

SKIN
Maintain the same naturally fair, refined skin tone.
Skin should remain:
realistic, luminous, healthy, and naturally textured.
Preserve realistic pores and subtle skin texture.
Do not make the skin suddenly whiter, darker, warmer, cooler, waxy, plastic, or artificially smooth in different shots.

HAIR
Preserve the same hairstyle:
thick, silky, naturally straight, jet-black long hair.
Keep consistent:
hairline
hair color
hair density
overall length
hair texture
overall hairstyle
The position of the hair may naturally change depending on camera angle and gravity, but the underlying hairstyle must remain the same.

BODY IDENTITY
Maintain the same adult female body proportions across all images.
Preserve:
shoulder width
neck length
torso proportions
waist position
waist-to-hip relationship
leg length
overall height-to-body ratio
Do not make her taller, shorter, heavier, thinner, or anatomically different between views.

COSTUME IDENTITY
Treat the costume as the exact same outfit across all views.
Permanent costume identity:
deep crimson oriental haute couture gown + luxurious golden long-sleeved robe + emerald-green gemstone jewelry + gold jewelry + wide decorative waist belt + gold tassels.
Preserve:
crimson base color
gold embroidery
oriental ornamental patterns
emerald centerpiece
golden robe
gold tassels
waist belt structure
jewelry aesthetic
Do NOT redesign the costume from one camera angle to another.
Only areas that are physically hidden from the available reference images may be reasonably reconstructed according to the established costume design.

VISUAL IDENTITY
Always preserve the same visual identity:
Oriental luxury × contemporary haute couture × mysterious fantasy × cinematic photorealism
Never transform the character into:
anime, CGI, 3D artwork, game character, illustration, low-budget cosplay, or generic AI beauty.

CONSISTENCY PRIORITY
When a local detail conflicts with the reference images:
prioritize preserving the character's identity over inventing new local details.
This is the same person.
Do not reinterpret her as a new character.

## 中文版 (Chinese Version)

【CHARACTER IDENTITY LOCK — 最高优先级】
以下内容定义角色的固定视觉身份。
无论后续生成什么角度、什么场景、什么动作、什么镜头、什么光线，都必须保持以下特征高度一致。

固定人物身份
一名成年年轻东方女性时装模特。
她不是不同的人物，也不是重新设计的新角色。
后续所有图片都必须表现为：
同一个真实存在的成年女性。

固定面部身份
保持与参考图完全一致的核心面部身份：
椭圆形脸型
稳定的脸部宽高比例
相同的额头比例
相同的眉骨结构
相同的眼睛形状、大小、间距和眼角结构
相同的鼻梁高度、鼻尖形状和鼻翼比例
相同的嘴唇轮廓、厚度和嘴角形态
相同的下颌线
相同的下巴形状
相同的面部骨骼结构
相同的耳朵位置与形状
人物身份必须通过：
眼睛 + 鼻子 + 嘴唇 + 下颌 + 脸型 + 面部比例
共同锁定。
不要因为拍摄角度改变而重新设计五官。

固定肤色
保持稳定的白皙、细腻、自然肤色。
必须是：
真实皮肤纹理 + 自然毛孔 + 健康光泽。
不要因为不同场景而突然变成：
过白、过黄、过红、蜡像皮肤或塑料皮肤。

固定发型
保持：
浓密、乌黑、顺滑、自然直的长发。
核心特征保持一致：
发际线一致
发色一致
发量一致
长度一致
发质一致
允许不同视角下头发自然改变位置，但不能改变基础发型设计。

固定身体特征
保持相同的成年女性身体比例：
相同肩宽
相同颈部长度
相同腰线高度
相同腰臀比例
相同腿部长度
相同整体身高比例
身体不能因为镜头变化而变高、变矮、变胖、变瘦或改变人体结构。

固定服装身份
服装必须被视为同一套完整服装。
核心固定设计：
深红色东方高级定制礼服 + 金色长袖披肩式外套 + 祖母绿色宝石 + 金色珠宝 + 宽版装饰腰带 + 金色流苏
保持：
红色主色
金色刺绣
东方纹样
绿色祖母石
金色外套
金色流苏
腰带结构
珠宝风格
不能在不同视角中随机重新设计服装。
只有真正位于身体另一侧、参考图不可见的部分，才允许根据服装结构进行合理补全。

固定整体美学
始终保持：
东方奢华
+
现代高级时装
+
神秘幻想
+
电影级真实摄影
不要改变成：
动漫、CG、游戏人物、cosplay、插画、廉价写真。

身份一致性原则
如果某个局部细节与参考图冲突：
优先保持人物身份一致，而不是追求局部细节变化。
不要为了适应新的姿态、角度、场景而重新创造人物。
这是同一个人。
