# 《我的女友是丧尸》AI视频生成项目实现总结

## 项目概述
使用ComfyUI + Wan2.1模型生成丧尸题材浪漫短视频系列，包含20个场景，分4集，每集5个场景，每场景5秒视频，配套TTS配音和字幕。

## 技术架构
```
ComfyUI (Wan2.1 T2V) → 视频生成 → FFmpeg后期处理 → 成品视频
     ↓
TTS配音生成 → 音频处理 → 音视频合并
     ↓
字幕生成 → 字幕叠加 → 最终输出
```

## 实现过程

### 1. 环境准备
- **ComfyUI配置**: 使用`--lowvram`模式适配RTX 4060 Ti 16GB显卡
- **模型部署**: 
  - Wan2.1 T2V 1.3B模型
  - CLIP编码器: `umt5xxl_encoder.safetensors` (4096维度，嵌入tokenizer)
  - VAE模型: `Wan2.1_VAE.pth`
- **输出目录**: SMB共享 `\\192.168.1.9\ComfyUI-Output\wan2\我的女友是丧尸`

### 2. 模型转换与适配
- **问题**: 原始CLIP模型维度不匹配(768 vs 4096)
- **解决方案**: 创建Python脚本进行键名映射和维度转换
- **结果**: 生成兼容的`safetensors`格式CLIP编码器
- **验证**: 测试视频生成成功，确认模型工作正常

### 3. 工作流设计
- **基础工作流**: `workflows/wan21_test.json`
- **参数优化**: 
  - 分辨率: 832×480 (后期可调整)
  - 帧数: 41帧 (约2.5秒)
  - 采样步数: 25步
  - CFG Scale: 7.0
- **一致性策略**: 统一人物描述提示词保持角色一致性

### 4. 内容创作
- **剧本设计**: 20个场景，分4集，包含完整故事线
- **对话设计**: 融入徐州方言元素，增强地域特色
- **角色设定**: 东方年轻女性丧尸角色，统一外观描述

### 5. 自动化流水线
- **脚本开发**: `tools/zombie_pipeline.py` 批量处理脚本
- **功能模块**:
  1. 视频生成模块
  2. TTS配音生成模块
  3. 字幕叠加模块
  4. 音视频合并模块
  5. 视频拼接模块

### 6. 后期处理
- **字幕叠加**: 使用FFmpeg `drawtext` 滤镜
- **音频处理**: 
  - TTS配音: Edge TTS引擎
  - 音频标准化: `normalize=0` 保持原始音量
  - 混音策略: 原始音频10% + 配音75%
- **视频合并**: FFmpeg `concat` 滤镜拼接场景

## 技术挑战与解决方案

### 挑战1: VRAM限制
- **问题**: RTX 4060 Ti 16GB显存限制视频长度
- **解决方案**: 采用41帧分段生成，后期拼接
- **结果**: 成功生成所有场景，质量与时长平衡

### 挑战2: 角色一致性
- **问题**: 不同场景角色外观差异
- **解决方案**: 统一人物描述提示词，固定随机种子
- **结果**: 角色一致性达到可接受水平

### 挑战3: 音频同步
- **问题**: TTS配音与视频时长匹配
- **解决方案**: 动态调整配音速度，使用FFmpeg时间戳同步
- **结果**: 音画同步良好

### 挑战4: 中文路径兼容性
- **问题**: Windows系统中文路径编码问题
- **解决方案**: 使用临时目录+文件复制策略
- **结果**: 所有中文路径正常处理
