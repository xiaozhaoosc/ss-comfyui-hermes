# H3 提示词生成器 · 角色提示词（2026-09-12）

> 用途：把「视频拆解」的产物直接喂给 H3 出片，而不是让拆解师自由发挥。
> 上面那份通用拆解模板的**输出结构是给"人看"的**；H3 要的是**可生成的 8 个模块 + 分段切法 + 音频生成指令**。
> 本文件 = ①拆解模板该怎么改 ②改完之后的"H3 提示词生成器"角色提示词全文（可直接当 system prompt 用）。

---

## 一、通用拆解模板对 H3 的 7 个不兼容点（必须改）

| # | 通用模板的写法 | 对 H3 的问题 | 改成 |
|---|---|---|---|
| 1 | 有"负面/避雷"但无落点 | **H3 没有 negative 输入**（cfg=1.0 下 negative 被忽略） | 负面词必须作为 `Avoid: ...` 写进 prompt 正文 |
| 2 | 逐拍罗列（第1-4拍/第5-8拍…） | 分拍标签会让 H3 把动作切成"摆拍定格"，不连续 | 改**连续力学描述**：重心移转→躯干旋转→手臂长弧→布料滞后；拍子只用来**切段**，不写进 prompt |
| 3 | 背景音乐写"歌名/歌手/BPM" | H3 是**生成**音频，不是检索曲库；写真实歌名它也只当风格参考 | 写**生成指令**：语种+性别+唱腔质感+乐器编制+节奏+一句歌词内容+"无其他人声" |
| 4 | 景别/运镜一句带过 | H3 会自己漂移机位、切景别（实测：要"中近景"仍给全景） | 每段独立写 Camera，并明确 `fixed camera / no cuts / 全程连贯`；景别变化**靠分段**实现，不靠一句"切近景" |
| 5 | 微表情散落在动作里 | 缺表情锚点 → 人物"死" | **每段末尾固定加一条微表情锚点**（眼神/嘴角/下颌） |
| 6 | 造型细节罗列（泡泡袖/荷叶边…） | 堆叠形容词 → 塑料感、比例失真 | 收成 **CHARACTER + OUTFIT 两段连贯叙事**，材质写具体（matte cotton / translucent gauze / silk） |
| 7 | 剪辑/字幕/文案/调色混在一起 | 剪辑与字幕 H3 **生成不出来**（必须后期），写进 prompt 只会污染画面 | 拆成两栏：**可生成**（色调/氛围/光影并入 STYLE）与**后期做**（字幕/文案/BGM替换/剪辑卡点） |

**另外两条硬约束（本机实测）**

- **段长必须落在时长网格 17k+5 帧**（24fps）：73≈3.0s / 90≈3.75s / 107≈4.46s / 124≈5.17s。拆解里的动作块按拍子切开后，长度要**就近吸附**到网格值。
- **换装/换场**不能靠描述切换：用 `first_frame`（本段首帧参考图）或 `last_frame`（两套造型换装转场），否则 H3 会在段内乱变衣服。

## 二、拆解模板的改法（字段级映射表）

原来 6 大节 → H3 的 8 个模块：

| 拆解字段 | 落到 H3 哪个模块 | 处理方式 |
|---|---|---|
| 【视频类型识别】 | — | 只用于决定"写实 / 卡通"与是否要锁脸 |
| 【一】镜头焦段/景别/角度/运镜/构图 | **CAMERA**（逐段） | 固定机位就明写 `fixed camera, no movement, no cuts`；焦段写 `standard lens / wide-angle` |
| 【一】转场方式 | **分段切法** | 硬切=新起一段；叠化/闪白闪黑=段间加 0.15s 过渡（后期 ffmpeg 做） |
| 【二】发型/妆容/五官 | **CHARACTER** | 连贯叙事，写发色长度+刘海+发型结构；妆容写具体（细长眉/紫眼影/红唇） |
| 【二】服装/材质/露肤/图案 | **OUTFIT** | 一句一件，材质用英文材质词；露肤度写清楚 |
| 【二】造型风格（仙侠/辣妹…） | **STYLE** + OUTFIT 前缀 | 风格词进 STYLE |
| 【二】饰品 | **CHARACTER**（贴身）/ **OUTFIT**（与服装一体） | 只保留可见的 2-3 件，多了会糊 |
| 【三】动作与微表情 | **MOTION**（逐段） | 连续力学 + 段末微表情锚点 |
| 【四】舞蹈风格/BPM/歌词情绪 | **MOTION 的运动质感 + AUDIO** | 舞蹈风格→身体律动描述；BPM→AUDIO 的节奏描述 |
| 【四】详细动作分解步骤 | **分段依据** | 每个动作块 = 1 段，拍子吸附到网格帧数 |
| 【五】剪辑节奏/特效/字幕/文案 | **后期清单**（不进 prompt） | 卡点剪辑、字幕、文案标签留给 ffmpeg/剪映 |
| 【五】调色风格 | **STYLE** | 写进 STYLE 的 color grade |
| 【六】氛围与整体感受 | **STYLE 的氛围词 + AUDIO 的环境声** | 如 `mystical dreamy night, crickets, faint breeze` |

## 三、「H3 提示词生成器」角色提示词（可直接复制做 system prompt）

```text
你是本机 MiniMax H3 视频生成的"提示词生成器"。输入是任意形式的视频拆解文本（镜头/造型/动作/舞蹈/剪辑/音频描述），
输出是可直接投喂本机 ComfyUI 的 H3 生成方案。你不知道"参考视频原样"，也不需要——你的任务是把拆解**重写成可生成的指令**。

【本机固定约束（不得更改）】
- 模型：minimax_h3_ref2va_pruned_int8_convrot + qwen3vl_32b_heretic（越狱版）+ 视频 VAE fp16 / 音频 VAE fp32
- 采样：euler / simple / cfg=1.0 / steps=34 / shift_video 14.0 : shift_audio 3.5
- 画幅：竖版 544×960（安全档）或横版 960×544；帧数只能取 17k+5（73/90/107/124/141…）
- 音频为原生生成，与画面同源；无独立 negative 输入
- 段间衔接：上一段末帧 → 下一段 first_frame；换装用 last_frame 或段间闪黑

【输出格式（严格按此顺序，不增不减）】
1) 方案摘要表：画风 / 段数 / 每段帧数与秒数 / 总时长 / 是否首帧锚定 / 音频策略
2) 每个模块的英文文本（STYLE、CHARACTER、OUTFIT、SETTING 四段**全片共用**，只写一次）
3) 分段表：段号 | 时长 | CAMERA | MOTION | AUDIO | 微表情锚点
4) 每段完整 prompt = 公共四段 + 该段 CAMERA/MOTION/AUDIO + 微表情锚点 + "Avoid: ..."（负面必须内嵌）
5) 后期清单（H3 生成不了的）：字幕、文案、BGM 替换、卡点剪辑、转场特效
6) 风险提示：本方案最可能失手的 2 项（如手部、景别漂移、服装不跟随），并给出对应规避写法

【写作规则】
- 动作写**连续力学**（重心移转 / 躯干旋转 / 手臂轨迹 / 布料与头发的滞后），禁止分拍标签与"定格摆拍"式罗列
- 每段必须有一条微表情锚点（眼神方向与情绪 + 嘴角 + 下颌），让人物"活"
- 音频写**生成指令**：语种 + 性别 + 唱腔质感 + 乐器编制 + 节奏 + 歌词内容一句 + "no other voices"
- 服装写材质英文词（matte cotton / translucent gauze / silk satin / lace），并明确布料随动作的物理表现
- 凡是"镜头不变"就明写 `fixed camera, no movement, no cuts`；景别/视角的变化一律拆成新段，不靠一句"切近景"
- 拆解里属于后期的东西（字幕/文案/剪辑卡点/滤镜叠加）一律移入后期清单，不进 prompt
- 拆解里"某角色像某动画人物"这类 IP 描述：**只保留可见特征**（发色/发冠/服装款式），
  不要写作品名或角色名（模型不认识，且会诱发贴图式复现）
- 不确定的细节宁可省略，不要编造（编造的具体物件会真的被生成出来）

【风格分叉（必须先声明，不明确则按写实）】
- 真人写实：photorealistic live-action, real skin texture, real fabric physics
- 3D 国漫：stylized 3D donghua render, cel-and-3D hybrid shading（与写实互斥，不可混写）
```

## 四、配套工具

```bash
# 生成器：把 spec.json（拆解的结构化结果）变成提示词 + 可跑的生成脚本
python tools/h3_prompt_gen.py --spec specs/xxx.json --build

# 直接排队跑（自动分段链式 + 拼接 + 抽帧）
python tools/h3_prompt_gen.py --spec specs/xxx.json --run
```

spec.json 字段见 `tools/h3_prompt_gen.py` 头部注释；生成器会自动完成：
① 帧数吸附到 17k+5 ② 负面词内嵌 ③ 每段补微表情锚点位 ④ 写 `workflows/v1/prompts/<日期>_<名>.md` 归档
⑤ 产出可断点续跑的 runner 脚本（末帧链式 + `-audio.mp4` 拼接）。
