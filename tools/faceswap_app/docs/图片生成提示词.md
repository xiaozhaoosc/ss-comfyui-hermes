# FaceswapPro 视频换脸大师 - 图片生成提示词

> 本文档为 FaceswapPro 视频换脸大师产品宣传图生成提供标准化的 AI 绘图提示词（Prompt）。
> 适用于 SDXL、Seedream、Midjourney、Stable Diffusion 等主流文生图模型。

所有场景均可共用以下反向提示词，避免生成低质量或不符合预期的内容：


## 使用说明

### 1. 在 SDXL 中使用

- **推荐尺寸**：
  - `landscape_16_9`：1344 × 768（SDXL 自然宽屏比例）
  - `landscape_4_3`：1024 × 768
  - `square`：1024 × 1024
- **采样参数建议**：Steps 30-40，CFG Scale 6-8，Sampler `DPM++ 2M Karras` 或 `Euler a`
- **反向提示词**：复制本文档"通用反向提示词"到 Negative Prompt 框
- **建议**：开启 `Refiner` 模型（如 sd_xl_refiner_1.0）以获得更细腻的细节

### 2. 在 Seedream 中使用

- 直接粘贴英文 Prompt 到输入框
- 选择对应尺寸预设：
  - `landscape_16_9` → 16:9
  - `landscape_4_3` → 4:3
  - `square` → 1:1
- Seedream 对中文 prompt 同样友好，但英文效果更稳定，建议优先使用本文档英文 prompt
- 可适当调整"创意度"参数（建议 0.5-0.7）平衡画面感与提示词遵循度

### 3. 在 Midjourney 中使用

- 在 prompt 末尾追加尺寸参数：
  - `landscape_16_9`：`--ar 16:9`
  - `landscape_4_3`：`--ar 4:3`
  - `square`：`--ar 1:1`
- 建议追加质量参数：`--q 2 --s 750 --v 6`
- Midjourney 不支持独立的 negative prompt，可将反向词以 `--no` 参数附加，例如：
  `--no text, watermark, realistic face, signature`
- 若需去除通用反向词中的全部内容，可组合：`--no low quality, blurry, distorted, watermark, text, ugly, deformed, realistic human face, real person, celebrity, signature, logo`

### 4. 通用调优建议

- **风格统一性**：所有 prompt 已统一使用深色调 + 霓虹绿/青/紫配色，确保整套宣传图视觉风格一致
- **抽象化处理**：所有 prompt 均避免描述真实人脸，使用 "abstract face"、"wireframe"、"silhouette"、"stylized face" 等表达，规避肖像权风险
- **质量词组合**：`8k, highly detailed, professional` 为基础质量三件套，可根据需要追加 `ultra detailed`、`sharp focus`、`cinematic lighting`
- **迭代生成**：每个场景提供 2-3 个变体，建议各生成 4-8 张挑选最佳，必要时对 prompt 微调光线或配色词
- **后期处理**：生成后可使用 Photoshop / Figma 添加产品 Logo、文字、按钮等 UI 元素，使其更贴近真实宣传素材
