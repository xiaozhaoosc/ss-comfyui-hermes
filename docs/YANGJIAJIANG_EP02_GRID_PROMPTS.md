## 自动化切片使用方法

当您获得生成的 6 张大图后（例如命名为 `input/yang_ep02_grid01.jpg` ~ `input/yang_ep02_grid06.jpg`）：

```bash
# 一键自动全部切片为 54 张 544x960 关键帧
cmd /c python tools/yangjiajiang_ep02_grid_cutter.py --all-dir input

# 或单张切片 (例如 Grid 1):
cmd /c python tools/yangjiajiang_ep02_grid_cutter.py --image input/yang_ep02_grid01.jpg --grid 1
```

切片完成后，即可直接通过 `tools/yangjiajiang_ep02_pipeline.py` 提交 ComfyUI 渲染！
