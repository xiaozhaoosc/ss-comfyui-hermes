# AI 漫剧智能体团队 2.0 — 复盘报告

> 复盘对象：WorkBuddy + 混元 HY3 搭建的「6 执行 + 1 总调度」漫剧智能体团队
> 输入基线：1 篇约 3700 字短篇小说
> 交付目标：3 集竖屏漫剧全链路资产（大纲 → 角色 → 美术 → 剧本 → 分镜投产包）
> 依据文档：[ai-comic-drama-agent-pipeline.md](./ai-comic-drama-agent-pipeline.md)

---

## 一、项目概况

| 维度 | 内容 |
|---|---|
| 团队构成 | 6 个执行角色 + 1 个总调度（钟秉钧） |
| 底层技能 | `eternityspring/shuohao-skills`（Apache-2.0），Node 18+，零 npm 依赖 |
| 主力模型 | 混元 **HY3**（免费） |
| 执行架构 | 节点无直连，全部经总控中转 |
| 质量体系 | 5 道技能共 **52 道质量门**（14 + 10 + 10 + 18） |

## 二、目标 vs 结果

| 目标 | 实际达成 | 判定 |
|---|---|---|
| 大纲落地产出 | novel-outline 通过 14 道门 | ✅ 达成 |
| 角色设定 + 音色锚点 | 苏晚、收银员双角色卡 | ✅ 达成 |

**总体判定**：全链路资产 100% 产出，成片环节未闭环。项目属「验证成功、成片待补」。

## 三、执行过程复盘

### 3.1 实际链路

```
章立纲(大纲) → 郝传神(人物) → 陆定景(美术) → 言成章(剧本) → 乔定帧(分镜)
```

### 3.2 亮点

1. **总控中转机制有效防失真** — 执行节点无直连，每条信息多一次核对，避免上游产物被下游私改。
2. **质量门打回机制严格** — 未过门即回炉，不允许带已知问题流转，保证下游输入干净。
3. **标准化锚点可追溯** — 每张设定卡附带可复制提示词与版面指令，避免「回头猜当初怎么写的」。
4. **串行自动化程度高** — 全程几乎无需人工干预，仅观察进度条。

### 3.3 摩擦点

| 摩擦点 | 现象 | 影响 |
|---|---|---|
| 串行无并行 | 5 节点依次执行 | 单点阻塞会拉长整体等待 |
| 头像积分消耗 | 默认生成 8 张团队头像 | 非必要支出 |
| 一致性未闭环 | 视频人脸/服装漂移 | 资产无法直接转成片 |
| 出图需外部回填 | 依赖 GPT 批量出图后手动回填 | 引入人工环节 |

## 五、成本复盘

### 5.1 实际消耗

| 项 | 积分 | 占比 |
|---|---|---|
| HY3（技能 / 大纲 / 设定集） | **0** | 0% |
| 团队头像 ×8 | 少量 | 低 |
| 单条测试视频 | ≈200 | 主要支出 |
| **合计实付** | **≈200+ 少量** | — |

### 5.2 单价参照

| 项目 | 单价 |
|---|---|
| 混元 文生图 / 图生图 | 5–10 / 张 |
| Seedance 即梦 2.5 视频 | 50–100 / 5 秒 |

### 5.3 成本结论

- 核心结论成立：**赋能全在免费 HY3，积分只花在头像和测试视频上**。
- 若批量成片，视频环节将成为成本主战场：以 70 切计，单条 50–100 积分的成本将迅速放大，**必须走 0 积分替代路线**。

## 六、问题与风险

| 级别 | 问题 | 根因 | 风险 |
|---|---|---|---|
| 高 | 成片一致性不足（人脸/服装） | 视频模型跨镜头一致性弱 | 无法直接交付成片，需二次精修 |
| 中 | 视频成本随切数线性放大 | 按秒计费 | 全片成本不可控 |
| 中 | 出图依赖外部手动回填 | `character-refs` 能力边界 | 引入人工断点 |
| 低 | 头像默认 8 张 | 未走「提前传图」 | 小额浪费 |
| 低 | 时长口径差 8 秒 | 剧本/分镜折算规则不同 | 排片对时误差 |

## 七、经验沉淀

1. **架构层**：多智能体协作的可靠性来自「总控中转 + 执行节点无直连」，而非节点本身能力。
2. **质量层**：质量门必须前置到每个节点的出口，打回机制是防污染的关键。
3. **资产层**：标准化锚点（提示词 + 版面指令）是资产可复用、可回滚、可二次出图的前提。
4. **成本层**：免费模型承担文本与设定，付费模型只用于无法本地化的环节，是当前最优成本结构。

| P2 | 老大纲节点提前产出美术锚点，向人物/美术节点下沉 | 减少跨节点返工 |
| P2 | 依赖 H3 本地部署补齐音频输出能力 | 支持复杂分镜 |

## 十、一句话总结

**验证成功、成片待补**：本项目的真实产出不是 5 分钟的成片，而是一条可审计、可回滚、可二次出图的标准化资产流水线——这正是它对有 IP、卡在视觉化第一步的创作者的最大价值。
