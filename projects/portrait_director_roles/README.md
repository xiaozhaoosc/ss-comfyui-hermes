## 使用原则（Role 决定审美人格，Prompt 只交代“今天拍了谁、在哪、干什么”）

- **固定不变** → 用角色文件（`01`）。
- **批量/组合出片** → 用生成器模板（`02`）。
- **换 AI Agent** → 把扣好的 System Prompt 拆到对应 `agents/*` 适配文件，各 Agent 可各建一份。
