# ROLE 02 · 「人物写真生成器」模板（可组合出片）

> 基于 ROLE 01 衍生的**槽位化生成器**。Role 决定审美人格；本模板负责把“人物 / 服装 / 场景 / 动作”组合成可直接投喂模型的完整 Prompt。
> 目标：同一张脸 + 同一服装 + 同一身材比例 + 同一摄影风格，多机位批量出片。

## 用法

1. 填满以下槽位（没有的槽位可留空并删掉对应行）。
2. 组合时**先放角色（ROLE 01）**，再拼装 Template SLOTS，最后追加 `CAMERA:`。
3. 需要多机位时，单独复制 `完成体`，只改 `[CAMERA]`（正面/侧面/背面/全身/半身/近景）。

---

## TEMPLATE SLOTS（槽位化模板）

```text
[ROLE]
Natural Feminine Outdoor Portrait Director

[SUBJECT]
young adult Asian woman        <- 人物设定，如年龄/类型/脸型（多机位时固定不变）

[HAIR]
black hair, loosely pinned bun <- 发型（固定不变）

[WARDROBE]
cream fitted blouse + floral skirt  <- 服装（多机位时固定不变）

[LOCATION]
lush mountain stream          <- 场景

[ACTION]
crouching and gently picking peaches from the water  <- 动作

[PROPS]
woven basket filled with peaches  <- 道具

[ENVIRONMENT]
waterfall + mossy rocks + forest + wooden guesthouse  <- 环境

[WEATHER]
soft misty spring morning     <- 天气/时间

[CAMERA]
water-level, 35mm, f/2.8      <- 请填一种机位：正面 / 侧面 / 背面 / 全身 / 半身 / 近景 / 极低机位近水面

[COMPOSITION]
foreground water blur + subject sharp + atmospheric background

[LIGHTING]
soft diffused natural daylight

[COLOR]
forest green + pink + cream + warm amber

[MOOD]
tranquil, poetic, romantic, fresh

[STYLE]
cinematic photorealism
```

## 多机位批量出片（同一张脸/服装/风格）

围绕固定 `[SUBJECT] + [HAIR] + [WARDROBE] + [STYLE]`，仅替换 `[CAMERA]` 生成六种机位：
正面 → 侧面 → 背面 → 全身 → 半身 → 近景。
建议用 ComfyUI 固定 seed + 参考图锁定脸部，确保一致性。
